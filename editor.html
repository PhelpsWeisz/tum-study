GitHub token (needed only to publish)

Publishing commits index.html straight to main; GitHub Pages republishes in one to two minutes. You need a token once:

  1. Open github.com/settings/personal-access-tokens/new (signed in as PhelpsWeisz).
  2. Name it e.g. “tum-study editor”, choose an expiry, and under Repository access pick Only select repositories → tum-study.
  3. Under Permissions → Repository permissions set Contents: Read and write. Nothing else. Generate and copy it.

The token is used only for requests to api.github.com from this page. Without a token you can still edit, preview and download the file, then upload it on GitHub.
