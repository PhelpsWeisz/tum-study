GitHub token (needed only to publish)

This page is a plain file: it has no server and cannot see or store what you type. The token goes from your browser straight to api.github.com over HTTPS, and nowhere else. Publishing commits index.html to main; GitHub Pages republishes in one to two minutes. To create a token once:

  1. Open github.com/settings/personal-access-tokens/new (signed in as PhelpsWeisz).
  2. Name it e.g. “tum-study editor”, choose an expiry, and under Repository access pick Only select repositories → tum-study.
  3. Under Permissions → Repository permissions set Contents: Read and write. Nothing else. Generate and copy it.

Without a token you can still edit, preview and download the file, then upload it on GitHub (“Add file → Upload files”).
